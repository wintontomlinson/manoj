1.1 Variables

A variable stores data in memory. Python does not need type declaration. You just assign a value using = sign.

Variable memory mein data store karta hai. Python mein type likhne ki zarurat nahi. Bas = se value assign karo.

Line 1: Python creates a box called "name" and puts "Manoj" inside it
Line 2: Creates box "age" with number 30
Line 3: Creates box "pi" with decimal 3.14
Line 4: print() shows all three values on screen separated by space

Step by step:
Line 1: Python ek box "name" banata hai aur usme "Manoj" dalta hai
Line 2: "age" box mein 30 dalta hai
Line 3: "pi" box mein 3.14 dalta hai
Line 4: print() teeno values screen pe dikhata hai

2.1 if / elif / else

Conditional statements run different code based on conditions. if checks first, elif checks more, else runs when nothing matches.

Conditional statements condition ke basis pe alag code run karte hain. if pehle check karta hai, elif aur check karta hai, else tab run hota hai jab kuch match na ho.

marks = 75
if marks >= 90:

else:

Step by step:
Line 1: marks = 75
Line 2: Is 75 >= 90? No, skip this block
Line 4: Is 75 >= 60? Yes! Enter this block
Line 5: Print "B grade" (this runs)
Line 6-7: else is skipped because elif was true

Step by step:
Line 1: marks = 75
Line 2: Kya 75 >= 90? Nahi, skip
Line 4: Kya 75 >= 60? Haan! Is block mein jao
Line 5: "B grade" print hota hai
Line 6-7: else skip hota hai kyunki elif true tha

for loop repeats code for each item in a sequence (list, string, range). range(n) gives numbers from 0 to n-1.

for loop code ko har item ke liye repeat karta hai. range(n) 0 se n-1 tak numbers deta hai.

for i in range(5):

Line 6: Prints "H", then ch = "i", prints "i"

Step by step:
Line 1: range(5) se [0,1,2,3,4] milta hai. i 0 se shuru hota hai

Line 5: Loop "Hi" ke har character pe jata hai. Pehle ch = "H"
Line 6: "H" print hota hai, phir ch = "i", "i" print hota hai

count = 1

break stops the loop completely. continue skips current iteration and goes to next one.

break loop ko poora rok deta hai. continue current iteration skip karta hai aur next pe jaata hai.

for i in range(10):

At i=4,5,6: prints normally
At i=7: break stops entire loop immediately
Result: 0 1 2 (3 skipped) 4 5 6 (7 onwards stopped)

Lines 1-6: Loop 0,1,2... pe jaata hai. i=3 pe: continue print skip karta hai, i=4 pe jaata hai

2.7 map / filter / reduce

map() applies function to every item. filter() keeps items that pass a test. reduce() combines all items into one value.

map() function ko har item pe lagata hai. filter() wahi items rakhta hai jo test pass karein. reduce() sab items ko ek value mein combine karta hai.

from functools import reduce
nums = [1, 2, 3, 4, 5]

squares = list(map(lambda x: x**2, nums))
print(squares)  # [1, 4, 9, 16, 25]

evens = list(filter(lambda x: x%2==0, nums))
print(evens)    # [2, 4]

total = reduce(lambda a,b: a+b, nums)
print(total)    # 15

Step by step:
Line 1: Import reduce from functools module
Line 2: nums list has [1,2,3,4,5]
Line 4: map applies x**2 to each: 1,4,9,16,25
Line 7: filter keeps only even numbers (x%2==0): 2,4
Line 10: reduce adds all: 1+2=3, 3+3=6, 6+4=10, 10+5=15

Step by step:
Line 1: reduce functools module se import karo
Line 2: nums list mein [1,2,3,4,5] hai
Line 4: map har number pe x**2 lagata hai: 1,4,9,16,25
Line 7: filter sirf even numbers rakhta hai (x%2==0): 2,4
Line 10: reduce sab jodta hai: 1+2=3, 3+3=6, 6+4=10, 10+5=15

Try it

2.8 Recursion

Recursion is when a function calls itself. It needs a base case (stopping condition) or it will run forever.

Recursion tab hota hai jab function khud ko call kare. Base case (stopping condition) zaroori hai warna forever chalega.

def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)

print(factorial(5))  # Output: 120

Step by step:
Line 1: Define factorial function
Line 2-3: Base case: if n is 0, return 1 (stop here)
Line 4: Otherwise return n * factorial(n-1)
Call: factorial(5) = 5 * factorial(4) = 5 * 4 * factorial(3) = ... = 5*4*3*2*1 = 120

Step by step:
Line 1: factorial function define karo
Line 2-3: Base case: agar n 0 hai toh 1 return karo (yahan ruko)
Line 4: Nahi toh n * factorial(n-1) return karo
Call: factorial(5) = 5 * factorial(4) = 5*4*3*2*1 = 120

Try it

4.2 __init__ and self

__init__ is constructor (runs when object is created). self refers to the current object. Every method must have self as first parameter.

__init__ constructor hai (object bante hi run hota hai). self current object ko refer karta hai. Har method mein self first parameter hona chahiye.

class Student:
    def __init__(self, name, roll):
        self.name = name
        self.roll = roll
    
    def display(self):
        print(f"{self.name} - {self.roll}")

s1 = Student("Amit", 101)
s1.display()  # Amit - 101

Step by step:
Line 1: Define Student class
Line 2: __init__ takes self (auto), name, roll as parameters
Line 3-4: Store name and roll inside this object using self
Line 6-7: display method prints this object's data
Line 9: Create s1. __init__ runs: self.name="Amit", self.roll=101
Line 10: s1.display() prints "Amit - 101"

Step by step:
Line 1: Student class define karo
Line 2: __init__ self (auto), name, roll parameters leta hai

4.6 Magic Methods

Magic methods have double underscores (__name__). They let you define how objects behave with operators like +, -, print, len, etc.

Magic methods mein double underscores hote hain (__name__). Ye define karte hain ki objects +, -, print, len jaise operators ke saath kaise behave karein.

class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y
    
    def __add__(self, other):
        return Vector(self.x+other.x, self.y+other.y)
    
    def __str__(self):
        return f"({self.x}, {self.y})"

v1 = Vector(2, 3)
v2 = Vector(1, 4)
v3 = v1 + v2
print(v3)  # (3, 7)

Step by step:

Line 8-9: __str__ defines what print shows
Line 11-12: Create two vectors
Line 13: v1 + v2 calls __add__. Returns Vector(3, 7)
Line 14: print(v3) calls __str__. Shows "(3, 7)"

Step by step:
Line 2-3: x aur y coordinates store karo
Line 5-6: __add__ define karta hai ki + kya karega. Dono ke x jodo, dono ke y jodo
Line 8-9: __str__ define karta hai ki print mein kya dikhe
Line 11-12: Do vectors banao
Line 13: v1 + v2 __add__ call karta hai. Vector(3, 7) return hota hai
Line 14: print(v3) __str__ call karta hai. "(3, 7)" dikhta hai

5.5 Decorators

Decorators add extra functionality to functions without changing them. Use @decorator_name syntax above the function.

Decorators functions mein extra functionality add karte hain bina unhe change kiye. @decorator_name syntax function ke upar use karo.

def timer(func):
    import time
    def wrapper(*args):
        start = time.time()
        result = func(*args)
        end = time.time()
        print(f"Time: {end-start:.4f}s")
        return result
    return wrapper

@timer
def slow_add(a, b):
    import time; time.sleep(1)
    return a + b

print(slow_add(3, 4))  # Time: 1.00s then 7

Step by step:
Line 1: Define decorator function "timer" (takes a function as input)
Line 3: wrapper replaces the original function
Line 4: Record start time
Line 5: Run original function and save result
Line 6-7: Record end time, print difference
Line 8: Return original result
Line 11: @timer wraps slow_add with timer functionality
Line 16: Calling slow_add runs wrapper first, then original

Step by step:
Line 1: "timer" decorator function define karo (ek function input leta hai)
Line 3: wrapper original function ki jagah le leta hai
Line 4: Start time record karo
Line 5: Original function run karo, result save karo
Line 6-7: End time record karo, difference print karo
Line 8: Original result return karo
Line 11: @timer slow_add ko timer functionality se wrap karta hai
Line 16: slow_add call karne pe pehle wrapper run hota hai
