5. Type Casting

Widening (automatic): small type to big type. Narrowing (manual): big type to small type using (type).

Widening (automatic): chhota type se bada type. Narrowing (manual): bada type se chhota type, (type) lagana padta hai.

Widening: byte → short → int → long → float → double (automatic)
Narrowing: double → float → long → int → short → byte (manual cast needed)
Example: 
public class Casting {
    public static void main(String[] args) {
        // Widening (automatic)
        int a = 100;
        double b = a;
        System.out.println(b);  // 100.0

        // Narrowing (manual)
        double x = 9.78;
        int y = (int) x;
        System.out.println(y);  // 9
    }
}
Output:
100.0
9

2. Constructors

A constructor is a special method that runs when an object is created. It has the same name as the class.

Constructor ek special method hai jo object banate waqt chalta hai. Iska naam class ke naam jaisa hota hai.

Default Constructor:
ClassName() { }
Parameterized Constructor:
ClassName(int a, String b) { this.a = a; this.b = b; }

class Car {

        speed = 0;

        this.speed = speed;

        System.out.println(brand + " - " + speed + " km/h");
    }

public class Main {
    public static void main(String[] args) {

        c2.show();
    }
}

6. Polymorphism

Polymorphism means "many forms". Overloading = same method name, different parameters. Overriding = child redefines parent method.

Polymorphism ka matlab hai "many forms". Overloading = same method naam, alag parameters. Overriding = child parent ke method ko redefine karta hai.

Overloading (compile time):
void add(int a, int b) { }
void add(double a, double b) { }
Overriding (runtime):
class Parent { void show() {} }
class Child extends Parent { void show() {} }
Example: 
// Method Overloading
class Calculator {
    int add(int a, int b) { return a + b; }
    double add(double a, double b) { return a + b; }
}

// Method Overriding
class Shape {
    void draw() { System.out.println("Drawing shape"); }
}
class Circle extends Shape {
    void draw() { System.out.println("Drawing circle"); }
}

public class Main {
    public static void main(String[] args) {
        Calculator calc = new Calculator();
        System.out.println(calc.add(5, 3));
        System.out.println(calc.add(2.5, 3.5));

        Shape s = new Circle();
        s.draw();
    }
}
Output:
8
6.0
Drawing circle

3. Exception Handling (try/catch/finally)

Exceptions are runtime errors. Use try/catch to handle them. finally always runs.

Exceptions runtime errors hain. try/catch se handle karo. finally hamesha chalta hai.

Syntax:
try {
    // risky code
} catch (ExceptionType e) {
    // handle error
} finally {
    // always runs
}
Example: 
public class Main {

            System.out.println("Error: " + e.getMessage());
        } finally {
            System.out.println("Finally block executed");
        }
    }
}

Finally block executed

5. Custom Exceptions

You can create your own exception class by extending Exception.

Aap apni exception class bana sakte ho Exception ko extend karke.

Syntax:
class MyException extends Exception {
    MyException(String msg) { super(msg); }
}
Example: 
class InsufficientFundsException extends Exception {
    InsufficientFundsException(String msg) {
        super(msg);
    }
}

class Bank {
    int balance = 1000;

    void withdraw(int amount) throws InsufficientFundsException {
        if (amount > balance) {
            throw new InsufficientFundsException("Not enough balance!");
        }
        balance -= amount;
        System.out.println("Withdrawn: " + amount);
    }
}

public class Main {
    public static void main(String[] args) {
        Bank b = new Bank();
        try {
            b.withdraw(1500);
        } catch (InsufficientFundsException e) {
            System.out.println(e.getMessage());
        }
    }
}

Not enough balance!

6. try-with-resources

try-with-resources automatically closes resources like files and streams. No need for finally block.

try-with-resources automatically resources (files, streams) ko close karta hai. finally block ki zaroorat nahi.

Syntax:
try (Resource r = new Resource()) {
    // use resource
} catch (Exception e) {
    // handle
}
Example: 
import java.io.*;

public class Main {
    public static void main(String[] args) {
        try (BufferedReader br = new BufferedReader(
                new FileReader("test.txt"))) {
            String line;
            while ((line = br.readLine()) != null) {
                System.out.println(line);
            }
        } catch (IOException e) {
            System.out.println("File error: " + e.getMessage());
        }
        // br is automatically closed here
    }
}
Output:
(contents of test.txt or error message)

6. Synchronization

Synchronization prevents multiple threads from accessing the same resource at the same time. Use synchronized keyword.

Synchronization multiple threads ko ek hi resource ek saath access karne se rokta hai. synchronized keyword use karo.

Syntax:
synchronized void method() { }
// or
synchronized (object) { }
Example: 
class Counter {
    int count = 0;

    synchronized void increment() {
        count++;
    }
}

public class Main {
    public static void main(String[] args) throws Exception {
        Counter c = new Counter();

        Thread t1 = new Thread(() -> {
            for (int i = 0; i < 1000; i++) c.increment();
        });
        Thread t2 = new Thread(() -> {
            for (int i = 0; i < 1000; i++) c.increment();
        });

        t1.start();
        t2.start();
        t1.join();
        t2.join();

        System.out.println("Count: " + c.count);
    }
}
Output:
Count: 2000

1. AWT Basics

AWT (Abstract Window Toolkit) is Java's original GUI library. It uses Frame, Button, Label, and TextField.

AWT (Abstract Window Toolkit) Java ki original GUI library hai. Ye Frame, Button, Label, aur TextField use karti hai.

Syntax:
import java.awt.*;
Frame f = new Frame("Title");
Button b = new Button("Click");
f.add(b);
f.setSize(400, 300);
f.setVisible(true);
Example: 
import java.awt.*;

public class MyAWT {
    public static void main(String[] args) {
        Frame f = new Frame("AWT Example");
        Label l = new Label("Hello AWT!");
        Button b = new Button("Click Me");

        l.setBounds(50, 50, 100, 30);
        b.setBounds(50, 100, 80, 30);

        f.add(l);
        f.add(b);
        f.setSize(300, 200);
        f.setLayout(null);
        f.setVisible(true);
    }
}
Output:
(A window with label "Hello AWT!" and a button)

2. Swing (JFrame, JButton)

Swing is an improved GUI library. It uses JFrame, JButton, JLabel, and JTextField. It is lightweight and more flexible than AWT.

Swing ek improved GUI library hai. Ye JFrame, JButton, JLabel, aur JTextField use karti hai. Ye AWT se lightweight aur flexible hai.

Syntax:
import javax.swing.*;
JFrame frame = new JFrame("Title");
JButton btn = new JButton("Click");
frame.add(btn);
frame.setSize(400, 300);
frame.setVisible(true);
Example: 
import javax.swing.*;

public class MySwing {
    public static void main(String[] args) {
        JFrame frame = new JFrame("Swing Example");
        JLabel label = new JLabel("Hello Swing!");
        JButton btn = new JButton("Click Me");

        label.setBounds(50, 30, 150, 30);
        btn.setBounds(50, 80, 100, 30);

3. Event Handling (ActionListener)

Event handling responds to user actions like button clicks. Implement ActionListener interface and override actionPerformed().

Event handling user actions (jaise button click) pe respond karta hai. ActionListener interface implement karo aur actionPerformed() override karo.

Syntax:
import java.awt.event.*;
button.addActionListener(new ActionListener() {
    public void actionPerformed(ActionEvent e) {
        // handle event
    }
});
Example: 
import javax.swing.*;
import java.awt.event.*;

public class EventDemo {
    public static void main(String[] args) {
        JFrame f = new JFrame("Event Demo");

        lbl.setBounds(50, 100, 200, 30);

                lbl.setText("Button clicked!");
            }
        });

        f.add(lbl);
        f.setSize(300, 200);
        f.setLayout(null);
        f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        f.setVisible(true);
    }
}

(Clicking button shows "Button clicked!" in the label)

4. Singleton Pattern

Singleton ensures only one object of a class is created. It uses a private constructor and a static method to get the instance.

Singleton ensure karta hai ki class ka sirf ek object bane. Private constructor aur static method se instance milta hai.

Syntax:
class Singleton {
    private static Singleton instance;
    private Singleton() { }
    public static Singleton getInstance() {
        if (instance == null) instance = new Singleton();
        return instance;
    }
}
Example: 
class Database {
    private static Database instance;
    private String connection;

    private Database() {
        connection = "Connected to DB";
    }

    public static Database getInstance() {
        if (instance == null) {
            instance = new Database();
        }
        return instance;
    }

    public String getConnection() {
        return connection;
    }
}

public class Main {
    public static void main(String[] args) {
        Database db1 = Database.getInstance();
        Database db2 = Database.getInstance();
        System.out.println(db1.getConnection());
        System.out.println(db1 == db2);  // same object
    }
}
Output:
Connected to DB
true

5. Factory Pattern

Factory pattern creates objects without specifying the exact class. A factory method decides which class to instantiate.

Factory pattern objects banata hai bina exact class specify kiye. Factory method decide karta hai ki kaunsi class ka object banega.

Syntax:
interface Product { }
class ConcreteProduct implements Product { }
class Factory {
    Product create(String type) { ... }
}
Example: 
interface Shape {
    void draw();
}

class Circle implements Shape {
    public void draw() { System.out.println("Drawing Circle"); }
}

class Rectangle implements Shape {
    public void draw() { System.out.println("Drawing Rectangle"); }
}

class ShapeFactory {
    Shape getShape(String type) {
        if (type.equals("circle")) return new Circle();
        if (type.equals("rectangle")) return new Rectangle();
        return null;
    }
}

public class Main {
    public static void main(String[] args) {
        ShapeFactory factory = new ShapeFactory();
        Shape s1 = factory.getShape("circle");
        Shape s2 = factory.getShape("rectangle");
        s1.draw();
        s2.draw();
    }
}
Output:
Drawing Circle
Drawing Rectangle
