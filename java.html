// Inheritance & Polymorphism
class Shape {
    String name;
    Shape(String name) { this.name = name; }
    double area() { return 0; }
    void display() {
        System.out.printf("%s: Area = %.2f%n", name, area());
    }
}

class Circle extends Shape {
    double radius;
    Circle(double r) { super("Circle"); this.radius = r; }
    double area() { return Math.PI * radius * radius; }
}

class Rectangle extends Shape {
    double l, w;
    Rectangle(double l, double w) { super("Rectangle"); this.l=l; this.w=w; }
    double area() { return l * w; }
}
Inheritance lets a class (child) acquire properties of another (parent). Method overriding allows child to provide its own implementation.
Inheritance se ek class (child) doosri class (parent) ki properties le sakti hai. Method overriding mein child class apna implementation de sakti hai.

Packages import try/catch finally throws Custom Exceptions
Java 
// Exception Handling
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Cannot divide by zero!");
} catch (Exception e) {
    System.out.println("Error: " + e.getMessage());
} finally {
    System.out.println("Always executes.");
}
try block contains risky code. catch handles specific exceptions. finally always executes regardless of exception. Multiple catch blocks handle different exception types.
try block mein risky code hota hai. catch specific exceptions handle karta hai. finally hamesha execute hota hai chahe exception aaye ya nahi. Multiple catch blocks alag-alag exception types handle karte hain.

// Singleton Pattern
public class Database {
    private static Database instance;
    private Database() {} // private constructor
    
    public static Database getInstance() {
        if (instance == null) {
            instance = new Database();
        }
        return instance;
    }
}

// Factory Pattern
interface Shape { void draw(); }
class CircleShape implements Shape {
    public void draw() { System.out.println("Drawing Circle"); }
}
class RectShape implements Shape {
    public void draw() { System.out.println("Drawing Rectangle"); }
}

class ShapeFactory {
    Shape getShape(String type) {
        if (type.equals("circle")) return new CircleShape();
        if (type.equals("rect")) return new RectShape();
        return null;
    }
}
Design Patterns are proven solutions to common software problems. Singleton ensures only one instance exists. Factory creates objects without exposing creation logic.
Design Patterns common software problems ke tested solutions hain. Singleton ensure karta hai ki sirf ek instance bane. Factory objects create karta hai bina creation logic expose kiye.
